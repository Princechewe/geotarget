# GeoTarget

**AI-assisted geospatial mineral exploration intelligence for Africa.**

GeoTarget is an early-stage exploration technology concept being developed by ANVOC Engineering Limited.

The platform is intended to integrate geological, geophysical, geochemical, remote-sensing, terrain, and historical exploration data into a single spatial decision-support environment.

Its purpose is to help exploration teams:

- combine fragmented geoscience datasets;
- identify prospective zones and anomalies;
- rank exploration targets;
- understand the evidence supporting each target;
- identify data gaps and uncertainty; and
- prioritise where field verification should occur next.

## Proposed Workflow

Geological Data + Geophysics + Geochemistry + Remote Sensing + Historical Records

↓

Spatial Integration and Feature Extraction

↓

Prospectivity and Anomaly Analysis

↓

Ranked Exploration Targets

↓

Focused Field Verification

↓

Updated Target Confidence

## Current Stage

**Concept / Pre-incubation**

GeoTarget is not yet a deployed product.

ANVOC Engineering Limited already works with GIS, hydrology, hydrogeology, simulation modelling, field investigation, environmental data, and mining-sector technical analysis. GeoTarget will build on these existing capabilities to develop a dedicated mineral-exploration intelligence platform.

## Initial Development Focus

The first prototype will focus on:

1. GIS-based geoscience data integration
2. Remote-sensing and terrain analysis
3. Transparent prospectivity scoring
4. Target ranking and visualisation
5. Field-verification recommendations
6. Progressive integration of artificial intelligence and machine learning

## Philosophy

GeoTarget is not intended to replace geologists or field exploration.

Its purpose is to help technical teams answer a more practical question:

> **Where should we investigate next, and why?**
